# Projektinitialisierungsantrag «redbox»

Noel Kohn, Maksym Shepetko, Henry R. Schellenberg

## Projekt-Idee
Die geplante Webapplikation bietet Mail-Service, kurzfristiges Textspeichern und ein Upload-Tool. Der Mail-Service läuft über Cloudflare, die eigene Oberfläche zeigt E-Mails an und erlaubt das Senden von Nachrichten.

Die gesamte Applikation wird auf einem Homeserver gehostet. Ziel ist maximale Sicherheit und Minimierung von Zugriffen durch Drittanbieter. Keine Nutzung der Daten für Werbung oder andere Fremdzwecke. Registrierung erfolgt ausschliesslich über einen einzigartigen Registrationscode, ausgegeben durch das Team, um Missbrauch wie Spam, Werbung oder Phishing zu verhindern.

Die Plattform wird auf der Domain «redbox.cx» betrieben.

## Problem
Persönliche Daten werden oft missbraucht oder unzureichend geschützt.
